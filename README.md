# ANIT — Associação Nacional de Instrutores de Trânsito

Site institucional estático e responsivo, desenvolvido em HTML, CSS e JavaScript puro.

## Publicação pelo GitHub Pages
1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)).
5. Salve e aguarde a URL ser disponibilizada pelo GitHub.

## Estrutura
- `index.html`: site completo, estilos responsivos e interações.

## Antes de divulgar
- Confirmar o nome oficial e a situação institucional da associação.
- Inserir logotipo oficial, se houver.
- Configurar e-mail, telefone/WhatsApp e canal real para receber contatos.
- Revisar estatuto, critérios de associação e qualquer informação sobre serviços.
- Publicar política de privacidade compatível com a LGPD caso passe a coletar ou armazenar dados.

O formulário atual valida os campos e tenta copiar o resumo da mensagem; ele não envia nem armazena informações em servidor.
